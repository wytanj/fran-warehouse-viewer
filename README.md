# CT Hub #11-18 — Warehouse Racking Viewer

Interactive 3D layout viewer for **CT HUB, UNIT #11-18, 11TH STOREY** (Fran / Heyfran).

## Footprint
- **7.100 × 13.100 m** = **91.77 m²** (plan B1)
- Source: BASE ARCHITECTURAL PLAN (scale indicative)

## Options
- **A — Long-aisle**: double-deep light-duty / longspan along long walls, main aisle ≥ 1.2 m, staging ~2.5 m at entrance
- **B — Cross-bay**: shorter runs perpendicular to long walls, pick aisles ~1.1 m

## Assumptions
- Clear ceiling **3.0 m** (ops; not on sheet)
- Rack clear height **1.9 m**
- Light-duty boltless / longspan (not selective pallet)
- WC/MV + entrance kept clear

Open `index.html` via any static host (CDN loads Three.js).
